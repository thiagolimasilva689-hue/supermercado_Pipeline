 Pipeline de Vendas - Supermercado

Pipeline ETL completo: extração de CSV sujo, limpeza com Pandas, carga no SQLite e visualização no Power BI.

## Objetivo

Transformar uma base de vendas bruta (com nulos, duplicatas e tipos errados) em dado confiável para análise de negócio.

## Tecnologias

- **Python 3.14** — linguagem principal
- **Pandas** — limpeza e transformação
- **SQLite** — armazenamento do dado tratado
- **Power BI** — visualização
- **Git/GitHub** — versionamento
